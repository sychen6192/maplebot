# 職業範本：射程、追擊、拉開距離該設多少

同一張地圖換個職業，真正要改的只有三個數字。近戰射程短、要走過去打；
遠程射程長、站著打，但怪貼上來要退開。

| | 近戰（戰士 / 刀賊） | 遠程（射手 / 標賊 / 法師） |
|---|---|---|
| `attack.range_px` | 55 | 110 |
| `attack.vertical_range_px` | 35 | 35 |
| `chase_px` | 280 | 0 |
| `keep_away_px` | 0 | 45（法師 / 標賊）；0（射手） |

單位都是以 790px 寬的 playfield 為基準，實際視窗較大時程式會自動等比例放大
（`attack_auto_scale`），所以換解析度不用重調。

## 這些數字怎麼來的

`range_px: 55` 是**實測**的：連拍攻擊動畫，短劍揮擊的紫色斬擊只延伸到角色
中心左右約 110px（1920 視窗），換算成 790 基準約 45，抓 55 留餘裕。

遠程的 110 是照「遠程約等於近戰兩倍」的比例推的，**沒有實測過**。弓在楓谷
的實際射程比這更遠，但射程開太大只會對著構不到的怪空揮（沒經驗，還會觸發
「打很久沒進展」的保護），所以寧可從小的開始加。

`vertical_range_px: 35` 也是實測的：同一層的怪跟角色中心差約 23px；站在
乾草堆上時腳下那排蝸牛差 112px、半空中的繩子差 199px——後兩者都打不到。
35（1920 上 85px）剛好只留同層。

## 自己量一次（30 秒，比猜準）

```bash
python tools/debug_view.py --profile config/profiles/你的.yaml --snapshot check.png
```

圖上會畫出**青色的攻擊範圍框**。跟你實際打得到的距離對一下：

- 框比實際打得到的遠 → 會對著構不到的怪空揮，`range_px` 調小
- 框比實際打得到的近 → 明明貼臉了卻不打，`range_px` 調大

## 三個參數各自在做什麼

**`attack.range_px`** — 怪進到這個框裡就打。太大＝空揮，太小＝該打不打。

**`chase_px`** — 看得到怪但不在攻擊框裡，就走過去（0＝關掉，照原定巡邏
路線走掉）。近戰非開不可，不然畫面上站著五隻可以一隻都不打。遠程通常不用，
射程本來就夠。設成攻擊距離的 3~5 倍；太大會被畫面邊緣的怪一直拉走。

**`keep_away_px`** — 怪靠得比這個近就先退開再打（0＝關掉）。遠程職業站樁
輸出時，怪貼上來只會挨打；退一步下個 tick 就打得到了，等於邊退邊射。
近戰要設 0——貼臉本來就是它要的。

## 還沒支援的

**瞬移走路 / 瞬移攻擊**（法師的位移技）沒有支援。走位目前只會按方向鍵，
法師照樣能跑，只是移動比手動慢。
