# 手把手教學：從 clone 到掛機

兩條路做的是同一件事、共用同一份設定檔：

- **圖形介面（推薦）**：裝完（第 0 步）之後看[下一節](#用圖形介面推薦)，控制台會一步步帶你做
- **命令列**：第 1～6 步

命令列照順序做完就能跑，**大約 15 分鐘**。每一步都寫了「預期結果」，對不上就看文末疑難排解。

> 前提：Windows 10/11、遊戲用**視窗模式**。即時擷取和按鍵只支援 Windows；
> 只跑測試、拿截圖離線開發的話任何平台都行。
>
> 遊戲用**系統管理員**執行的話，終端機（或 `gui.py`）也要用系統管理員開。
> 不然 Windows 會默默丟掉所有按鍵：log 照常印出攻擊、喝藥，角色卻一步都不動。
>
> **建議把遊戲視窗開在 800x600 左右**。大視窗（2560x1440 全螢幕）不是不能用，
> 但辨識比較慢、之後每個座標都要重校正。

> 好消息：怪物偵測是**零設定**的（靠 sprite 的黑色描邊找怪），
> 不用截模板、不用訓練、不用標註。巡邏點也可以讓它自己量。

## 第 0 步：安裝

```powershell
git clone https://github.com/sychen6192/maplebot.git
cd maplebot
pip install -r requirements.txt
pytest -q
```

**預期結果**：最後一行是 `xxx passed`。測試完全離線，不用開遊戲。

> 想用虛擬環境（推薦）就改用 [uv](https://docs.astral.sh/uv/)：
> ```powershell
> powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
> uv venv && .venv\Scripts\activate && uv pip install -r requirements.txt
> ```
> 之後每次開新終端機都要先 `.venv\Scripts\activate`。

## 用圖形介面（推薦）

```powershell
python gui.py
```

開出來的是「mapleai 控制台」。左邊是**準備**清單和設定分頁，右邊是執行卡、
即時狀態和日誌。遊戲要先開好、進到要練功的地圖、角色站好。

> 遊戲用系統管理員身分執行的話，控制台也要：開始功能表搜尋「命令提示字元」→
> 右鍵「以系統管理員身分執行」→ `cd` 到專案資料夾 → `python gui.py`。
> `gui.py` 的右鍵選單沒有這個選項（.py 檔不支援），一定要從提權的終端機開。

### 準備分頁：照 7 步往下做

**下一步該按的按鈕是藍色的**，跟著藍色按就對了。步驟不會鎖住，先後關係寫在每一步的說明裡。

**這台電腦**（做一次就好，換電腦或改遊戲視窗大小才要重做）

1. **遊戲視窗**：下拉選單選你的遊戲視窗。找到會打勾、顯示視窗大小。
2. **校正**：按「開始校正」，會跳出框選視窗（沒看到就找工作列）。
   - 先框**小地圖**：只框地圖畫布本體，**不要框到標題列**——標題列上的黃色圖示會被當成角色。按 Enter
   - 再框 **playfield**：角色和怪活動的那一塊，不含下面的狀態列
   - HP／MP／EXP 條多半會自動找到。完成後自動寫回 `config/local.yaml`
3. **截角色名牌**：按「截名牌」，在跳出的截圖上框住角色腳下那塊深色底的名字，按 Enter。
   不截的話程式不知道角色在哪，會把自己當成怪站著打。換角色要重截
4. **辨識自檢**：按「自檢」，會跳出標好框的截圖和逐項判讀。確認：
   - HP／MP／EXP 的數字跟遊戲裡一樣
   - 小地圖上的綠圈在角色身上
   - 怪物被黃框框到
   - 紫色十字在角色身上

   有 × 的先照旁邊的按鈕處理，都對就按「看起來都對 √」

**這張地圖**（換地圖或換角色就另存一份）

5. **我的地圖設定**：先從上面的「地圖」下拉選一個跟你職業接近的範本——
   「範本：近戰（戰士 / 刀賊）」「範本：遠程站樁（法師 / 標賊）」「範本：遠程（射手）」——
   再按「另存…」取個名字（例如「弓箭手訓練場一」）。範本本身不會被改到
6. **巡邏路線**：按「到巡邏分頁」。
   - **單層地圖**：選「自動探邊」就好，開場會自己往左右走到撞牆、量出範圍
   - **多層地圖或想自己決定路線**：按「● 錄製路線」→ 回遊戲照平常走一趟（爬繩、跳平台都可以）→
     回來按「■ 停止錄製」→ Ctrl+S 存檔
7. **預演一次**：按「開始預演」。照常看畫面、做決策、寫日誌，但**一個鍵都不按**。
   看右邊執行卡：開場自檢有過、決策看起來合理，再按「■ 停止…」。
   巡邏用自動探邊的話，預演時一定量不到範圍（不按鍵角色不會動），會顯示灰色說明，這是正常的

### 其他分頁：填一次就好

| 分頁 | 要填的 |
|---|---|
| 打怪 | 攻擊鍵、攻擊方式、水平距離（近戰 55、遠程 110，見 [職業範本.md](../config/profiles/職業範本.md)；以 790 寬為準，不用自己換算） |
| 巡邏與 buff | 巡邏點；最多 8 組「buff 鍵 每 N 秒」 |
| 藥水與安全 | HP／MP 藥水鍵與喝藥線（要高於停機線）、幾分鐘沒經驗就暫停、最長掛機 |
| 辨識 | 通常不用動；抓不到怪就把「描邊黑度」調高 |

- **按鍵欄位**：點一下，再按遊戲裡的那個鍵就綁好。Esc 取消、右鍵清空；數字鍵盤、Caps Lock 這類送不進遊戲的鍵會當場擋下
- 標籤變**琥珀色** = 改了還沒存，**Ctrl+S** 儲存；**紅色 ×** = 填錯了，底下的「前往」帶你過去
- 滑鼠停在欄位上會顯示說明和建議範圍
- 群組旁的標章說明存到哪裡：藍色「Profile・這張地圖」寫進地圖設定檔，紫色「Config・這台電腦」寫進 `config/local.yaml`

### 開始掛機

右邊選「**實戰**」，按「**▶ 開始打怪**」。準備還沒做完的話會先提醒你。
執行中左邊的設定會鎖住——設定在按下開始時就讀進去了，要改請先停止。

- **執行卡**：綠色「執行中」；琥珀色「讓過中／已暫停」（例如小地圖出現其他玩家），
  會寫出原因；紅色「自動暫停／已停機」會寫出原因，附一個按鈕打開出事當下的截圖
- **HP 色條上的細線**：琥珀色是喝藥線、深紅色是停機線
- **操作**：遊戲裡 `F9` 暫停／繼續、`F12` 停止；控制台的「‖ 暫停」「▶ 繼續」
  （繼續時會把遊戲帶回前景）「■ 停止…」
- **收工**：執行卡會寫這一場跑多久、賺多少經驗，「開啟收工報告」看完整報告；
  日誌勾「只看問題」只留警告和錯誤
- 控制台縮到工作列時，視窗標題也會顯示狀態和 HP

### 卡住時

| 症狀 | 處理 |
|---|---|
| log 有動作、角色完全不動 | 系統管理員權限，見本節開頭 |
| 一直原地打自己 | 重截角色名牌，再自檢看紫色十字有沒有在角色身上 |
| 抓不到怪 | 「辨識」分頁把描邊黑度調高 |
| 準備分頁底下「環境檢查」有 ！ 或 × | 照那一行的說明修，例如「射程設定」互相抵銷 |

其他狀況見[疑難排解](#疑難排解)。

## 第 1 步：告訴程式你的遊戲視窗叫什麼

預設是 `新楓之谷：經典版`。如果你的客戶端標題不一樣（有些是英文的 `MapleStory`，
私服則各有各的名字），程式找不到視窗時會**把目前開著的視窗全部列出來**，
照抄一段進來就好。

建立 **`config/local.yaml`**——你的個人設定都放這裡，更新程式不會被蓋掉：

```yaml
window:
  title: "新楓之谷：經典版"   # 子字串比對即可，不分大小寫
```

## 第 2 步：校正（你只要框小地圖和 playfield）

```powershell
python tools/calibrate.py --write     # 直接寫回 config/local.yaml
```

HP／MP／EXP 三條狀態列會**自動找到**：它們是遊戲畫的 UI，顏色固定、永遠並排在
畫面底部，沒道理要你拿滑鼠去拉。終端機會印出每一條的座標和當下讀出來的百分比，
**跟遊戲裡顯示的對一下**，差很多就是找錯了。

剩下兩個 region 會跳出框選視窗，**滑鼠拖出矩形 → 按 Enter**（按 `c` 跳過）：

| Region | 框什麼 |
|---|---|
| `minimap` | 小地圖的**地圖畫布**本體（不含標題列） |
| `playfield` | 角色和怪物所在的那一大塊畫面（不含底部 UI 列） |

狀態列沒找到的話，`hp_bar`／`mp_bar`／`exp_bar` 也會一併跳出來讓你框：
只框色條本體，不含 `HP[...]` 文字和外框。想全部自己框就加 `--no-auto`。

**預期結果**：印出「已寫入 config/local.yaml」。它同時會記下**校正當下的視窗大小**
——之後你把遊戲視窗改大改小，主程式開場就會擋下來叫你重新校正，
而不是把 HP 讀成 0% 然後判定瀕死停機。

local.yaml 裡你自己寫的註解會留著，只改校正出來的那幾個值。檔裡還沒有那幾個 key
（例如上次跳過了某個 region）就只能整份重寫；原檔有註解的話，會先備份成
`config/local.yaml.bak` 並印出位置，已經有的 .bak 不會被蓋掉。

（不加 `--write` 就只印出來讓你自己貼。）

### 再截一次角色名牌

```powershell
python tools/grab_template.py --dir data/templates/ui --name player_nametag
```

框住角色腳下那塊深色底的名字（不用框很準）→ Enter。

**為什麼要做**：楓谷的鏡頭有跟隨延遲、走到地圖邊緣還會卡住，角色其實常常
不在畫面正中央（實測可偏 200px 以上）。程式要知道角色真正在哪，才能把角色
自己從怪物清單裡挖掉、把攻擊範圍對準角色。名牌上是你的角色名，別人的比不中，
所以它天生只找得到自己。沒有這張模板就退回組隊紅條（要先按 P 自己跟自己組隊），
兩個都沒有才假設角色在畫面正中央——那樣常常會把角色當成一隻怪，站在原地打自己打整晚。

## 第 3 步：驗證辨識（最重要的一步）

```powershell
python tools/debug_view.py --snapshot check.png
```

不開視窗，只存一張標註圖。終端機會印：

```
擷取尺寸: 800x600｜擷取方式: printwindow
playfield ROI: [8, 60, 790, 520]
  HP 100% | MP 100% | EXP 59%
  玩家小地圖座標: (36, 45)｜其他玩家: 0
  偵測到怪物: 3
  當下決策: Attack
```

打開 `check.png` 檢查五件事：

1. 小地圖上你的位置有**綠圈**
2. `HP xx% | MP xx% | EXP xx%` 跟遊戲畫面一致
3. 場上的怪有**黃框**
4. 沒有把樹、雲、UI 框成怪
5. 角色身上有**洋紅色十字**（角色定位）。沒有十字、或十字偏掉，見文末疑難排解「原地打自己」

> 寵物也會被框成怪（牠一樣有黑色描邊）。**最乾脆的解法是進遊戲把寵物收起來**；
> 想留著的話見文末疑難排解。

**抓不到怪或框錯**，只要調兩個旋鈕（`config/local.yaml`）：

```yaml
vision:
  outline_black_level: 8    # 抓不到 → 往上調（各客戶端不同，範圍見 config/default.yaml 的註解）；框到一堆背景 → 調低到 4
  outline_min_area: 300     # 框到小碎塊 → 調高；小怪被漏掉 → 調低
```

> 也可以用 `python tools/debug_view.py` 開即時視窗（按 q 離開），
> 但如果擷取方式是 `screen`，視窗蓋住遊戲會拍到自己，用 `--snapshot` 最保險。
> 沒開遊戲、手上只有截圖時加 `--source 截圖.png`，調門檻不必每次都進遊戲。

## 第 4 步：寫你的地圖 profile

```powershell
copy config\profiles\example.yaml config\profiles\mymap.yaml
```

打開 `mymap.yaml`，最少改這幾個地方：

```yaml
patrol:
  waypoints: auto           # ← 懶人寫法：開場自己左右走到撞牆，量出巡邏範圍

loot:
  key: z                    # 撿取鍵（不想撿就留空）

attack:
  key: ctrl                 # 你的攻擊技能鍵（楓谷預設 Ctrl）
  type: directional         # 原地放的技能（祭司 Heal 之類）改成 aoe
  range_px: 120             # 攻擊範圍，看武器（下表）

potions:
  hp: { key: pageup,   below_ratio: 0.50 }
  mp: { key: pagedown, below_ratio: 0.30 }

buffs:
  - { key: "8", every: 120, cast_seconds: 1.5 }   # 沒 buff 就整段刪掉
```

**`range_px` 要照武器調**。它是以 790px 寬的畫面為基準，**大視窗會自動等比例
放大**，所以換視窗大小不用重調。各武器起手值：

| 武器 | range_px | 武器 | range_px |
|---|---|---|---|
| 短劍 / 單手劍 | 120 | 拳套 / 標 | 500 |
| 雙手劍 / 斧 / 棍 | 160 | 弓 / 弩 | 600 |
| 槍 / 矛 | 200 | 攻擊魔法 | 400 |

不確定就用量的：`python tools/debug_view.py --snapshot check.png`，
圖上會畫出**青色的攻擊範圍框**，跟你實際揮砍打得到的距離對一下。
有設的話還會畫追擊範圍（淡藍框 `chase`）、後退距離（橘線 `keep away`）、
角色排除範圍（深灰框 `self`：框內的偵測一律當成角色自己）和找怪範圍（`search`）。
這幾個框互相套住就會互相抵銷——例如後退距離整個落在 `self` 裡，貼身的怪早就被濾掉，
永遠不會觸發後退。`tools/doctor.py` 的「射程設定」檢查的就是這件事。
框太大 = 對著構不到的怪空揮（沒經驗，還會觸發「打很久沒進展」自動去巡邏）；
框太小 = 明明貼臉了卻不打。

**`waypoints: auto` 是關鍵**——它會在開場自己往左右走到撞牆，量出可走範圍，
你不用先去量座標。單層練功圖用這個就夠了。

**多層地圖 / 想自己決定路線**：用錄製。`python gui.py` →「巡邏與 buff」分頁按
「● 錄製路線」→ 照平常的方式走一趟（爬繩、跳平台、定點放技能都可以）→ 回來按
「■ 停止錄製」→ Ctrl+S 儲存。程式會把軌跡壓成巡邏點自動填進去：折返點變成端點、小地圖 y 跳階的地方變成
爬繩點、站定按的鍵會掛在那個點上。方向鍵不會被錄進去——那由巡邏邏輯自己決定，
所以被怪打歪了也能自己走回路線上。

<details>
<summary>想自己指定巡邏點 / 多技能 / 多層地圖（點開）</summary>

**手動巡邏點**：先讀座標

```powershell
python tools/debug_view.py --track
```

一邊玩一邊看終端機印出的 `x=`，走到左端點記一次、右端點記一次：

```yaml
patrol:
  waypoints: [36, 91]
```

**多技能輪替**（大絕 + 主攻）：

```yaml
skills:
  - key: v                # 範圍大絕：優先但條件嚴格
    type: aoe
    cooldown: 30
    min_mobs: 3           # 至少 3 隻才放，不浪費在單隻怪身上
    min_mp: 0.2
    range_px: 400
  - key: ctrl             # 主攻：保底
    type: directional
    cooldown: 0.2
    range_px: 320
```

有 `skills:` 時 `attack:` 會被忽略。

**多層地圖**（要爬繩子）：見 `config/profiles/multilevel.yaml`，
用 `{x: 68, y: 20}` 指定「x 對準後爬到 y」。繩子的座標要自己用 `--track` 量。
</details>

## 第 5 步：先預演（不會按任何鍵）

```powershell
python main.py --profile config/profiles/mymap.yaml --dry-run
```

**預期結果**：每行 log 的決策要合理——

```
tick 3 | HP 100% MP 100% | 玩家 (36, 45) | 怪 2 | -> Attack
tick 4 | HP 100% MP 100% | 玩家 (36, 45) | 怪 0 | -> Loot
tick 5 | HP 100% MP 100% | 玩家 (40, 45) | 怪 0 | -> Move
```

看個一分鐘沒問題就 `Ctrl+C`。

> 用 `waypoints: auto` 的話，預演會先看到一串 `Probe`（探邊），沒多久就停機，
> log 說量到的可走範圍只有 0px：dry-run 不按鍵、角色沒動，探邊當然量不到東西。
> 這是預期的，正式執行時才會真的量。

## 第 6 步：正式執行

```powershell
python main.py --profile config/profiles/mymap.yaml
```

啟動後**點一下遊戲視窗**讓它保持在前景。

> 開跑前再用 `--snapshot` 確認一次角色身上有洋紅色十字（第 2 步截的名牌）。
> 名牌比不中時才會退回組隊紅條（按 P 自己跟自己組隊），那是備援，不是首選。

| 熱鍵 / 情況 | 行為 |
|---|---|
| `F9` | 暫停 / 繼續 |
| `F12` | 停止 |
| HP 掉到危險線（`safety.critical_hp_ratio`，預設 25%） | **先灌藥搶救**，不是馬上停機：停機後角色會站在原地繼續被打，掛整晚就是這樣死的。有設 `potions.hp_emergency` 的話，血低於它的門檻會先按那顆大瓶。要連續 3 幀都讀到低血、而且撐了 `safety.critical_hp_seconds`（預設 4 秒）還拉不回來，才停機 + 長嗶 + 截圖；設了 `panic_return_key` 會先回城再停 |
| HP 藥水用完 | 連喝 10 瓶、過了 8 秒 HP 都沒回升就判定用完，警報 + 截圖。設了 `panic_return_key` 就**趁血還沒見底回城停機**（等到危險線才走，回城卷也救不了站在怪堆裡的人）；沒設就每 20 秒試一瓶、繼續打 |
| 角色死亡 | 預設自動復活（`safety.auto_revive`）：HP 0% **而且**看到復活對話框，就用滑鼠點「確定」原地復活。`death_window_minutes`（預設 10 分鐘）內死滿 `max_deaths`（預設 3）次代表復活點一直被送死，停機等人來看 |
| 小地圖出現其他玩家 | 暫停動作 + 短嗶，人走了自動繼續 |
| 黑屏 / 找不到角色 | 自動暫停 + 嗶聲 + 截圖到 `logs/anomalies/` |
| 遊戲行程不見了 | 停機（見下面「沒人看著的時候」） |
| 卡在地形 | 自動跳一下脫困 |
| **10 分鐘沒賺到經驗** | 自動暫停 + 警報（代表技能鍵設錯之類的問題） |
| 跑滿 `safety.max_runtime_minutes` | 自己收工並照常出報告（預設 0 = 不限）。睡前開的 bot 不該跑到隔天中午 |

每 60 秒會印一次進度：

```
狀態：運行 12.3 分鐘 | tick 5904 | 攻擊 412 次 | 撿物 88 次 | 脫困 2 次
進度：EXP 63.4%｜累積 +1.32 等｜約 1.18 等/小時｜升級 1 次
```

完整紀錄在 `logs/run_*.log`。

### 沒人看著的時候：開跑前、跑的時候、收工後

掛機真正的難處不是會不會打怪，是**沒人看著的那幾個小時發生了什麼**。

**開跑前：`python tools/doctor.py --profile config/profiles/mymap.yaml`**。
套件、設定檔、region、profile、遊戲視窗一次查完，每一項都附「該動哪裡」；
有任何 ❌ 就回傳 exit code 1，可以寫進批次檔。它抓的是要先跑起來才會爆的那些：

- region 超出校正當下的視窗大小（超出畫面的 region 一律讀不到：血條那條會讓主程式開場就拒跑，小地圖那塊會讓角色一直讓過、幾秒後被看門狗暫停）
- 血條那排被框進 playfield（症狀：把 UI 當成怪，站在空地一直揮）
- `potions.hp.below_ratio` 不高於 `safety.critical_hp_ratio`（症狀：每次都要先掉進危險線才開始喝藥，搶救時間只剩 `critical_hp_seconds` 那幾秒）
- `mob_detector: yolo` 但模型檔不存在、`template` 但一張模板都沒有

（不加 `--profile` 檢查的是 `example.yaml`。）

**跑的時候：每分鐘那行「效能」**

```
效能：7.2/8 FPS｜perceive 96ms｜execute 12ms｜capture 8ms｜decide 0ms｜monitor 0ms｜超支 34%｜遊戲 12% CPU / 1650MB｜bot 25% CPU / 310MB｜系統 48% CPU / 63% RAM
```

`loop.fps: 8` 是**預算**不是保證：擷取加辨識超過 125ms，迴圈只會安靜地變慢，
你只覺得「有點鈍」。所以這行把每一段的平均耗時由慢到快排出來：

- 第一個數字是實際 FPS，斜線後是目標
- `超支` 是跑不完 125ms 預算的 tick 比例。超過兩成時 log 會另外警告一次，直接說慢在哪一段、該調什麼
- `execute` 包含按住技能鍵和方向鍵的刻意等待，不算進超支，數字大也不是效能問題
- 後面接的是遊戲、bot 和整台機器的 CPU／記憶體

怎麼調見文末疑難排解「反應變鈍」。

**跑的時候：遊戲行程監看**。每 5 秒看一次遊戲行程還在不在，**遊戲當掉、被關掉
或被踢下線就停機**——這是所有「遊戲不見了」的訊號裡最不會誤判的（黑屏偵測會被
讀圖騙、找不到角色會被換圖騙），不停的話 bot 會繼續把技能鍵和方向鍵送進桌面。
行程用遊戲視窗反查，開兩個客戶端也不會綁錯。這層要 `psutil`（`requirements.txt`
已經包含），沒裝就自動停用，其他功能照常。

**想邊跑邊看框**就加 `--preview`：開一個視窗即時顯示主迴圈當下這一幀的辨識結果，
會多吃一點 CPU，掛整晚不建議開。擷取方式是 `screen` 時別讓它蓋住遊戲，理由同第 3 步。

**收工後：`logs/reports/session_<時間>.{md,json,png}`**。log 是一萬行流水帳，
回答不了「這三小時到底怎麼樣」；報告是摘要：

- `.md`：累積經驗、每小時效率、攻擊次數（含每分鐘幾次）、補血／補魔次數、效能分段、遊戲記憶體峰值，以及警報次數和最近幾筆（什麼時候黑屏、什麼時候有人來）
- `.json`：同一份資料給程式讀，跨場次比較「這張地圖值不值得掛」
- `.png`：HP/MP/EXP、怪物數、FPS、遊戲記憶體四張小圖。要 `pip install matplotlib`，沒裝就只出前兩個

不想要就加 `--no-report`，或在 `config/local.yaml` 設 `report.enabled: false`。

## 疑難排解

| 症狀 | 解法 |
|---|---|
| **抓到的怪比想像中少** | 跑 `python tools/debug_view.py --snapshot check.png`，最後一行會直接告訴你原因與該調哪個旋鈕，例如「黑塊 146 個 -> 採用 3 個（太小 143、太大 0）」。另外可以開 `vision: { detect_hp_bars: true }` 多一道：打過的怪頭上有綠色血條，抓那個顏色就一定有怪。但**長草的地圖會把草地誤判成血條**（草綠跟血條綠只差十幾階），開之前一定要先 `--snapshot` 看標 `hpbar` 的框有沒有落在真的血條上，所以預設關閉 |
| 抓不到怪、**地上整排小怪都沒框到** / 框到背景 | 不是每個客戶端的 sprite 描邊都是純黑的，預設的 `vision.outline_black_level: 8` 可能整排漏掉。往上調抓更多、往下調（例如 4）抓更少；即時擷取和 JPEG 截圖各該落在哪個範圍，寫在 `config/default.yaml` 那一行的註解。小碎塊被框到、或小怪被當成雜訊濾掉，再調 `outline_min_area` |
| 幾隻怪被框成一大塊 | `outline_close_kernel` 調小（怪跟地形/彼此連在一起了），或 `outline_max_area` 調高 |
| **一直打自己的寵物** | 三個辦法，由可靠到不可靠：①**進遊戲把寵物收起來**（最乾脆，撿物有 `loot.key` 可代勞）②`vision: { outline_player_box: [220, 200] }` 把角色旁邊那塊直接挖掉（連貼身的怪也會一起挖掉）③`vision: { filter_followers: true }` 讓程式自己認寵物——它靠鏡頭捲動判別，**窄地圖鏡頭不捲就認不出來**，所以預設關閉 |
| **一直攻擊、完全不走路** | 多半就是在打寵物。連續打 12 秒位置沒變會自動讓路去巡邏，log 那條警告會說明；解法同上 |
| **原地打自己**（一直攻擊但經驗不動，`--snapshot` 上角色自己被黃框框住） | 角色定位沒抓到，挖掉「自己」挖錯了地方。①還沒截名牌就截一張：`python tools/grab_template.py --dir data/templates/ui --name player_nametag`（見第 2 步）②再跑 `--snapshot` 看洋紅色十字：**沒有十字**代表名牌和組隊紅條都沒抓到、退回了畫面中央，重截一張名牌、或自己跟自己組隊讓組隊紅條接手；**有十字但不在角色身上**就調 `vision.nametag_offset`（名牌中心到角色中心的位移，以 790px 寬為基準，往上是負的） |
| 開了 `filter_followers` 之後怪也不打了 | 表示判別在你這張圖不成立（鏡頭不捲動）。設回 `false`，改用上面的 ①或② |
| **反應變鈍**、大視窗很卡 | 先看 log 每分鐘那行「效能」（怎麼讀見第 6 步），它會說慢在哪一段。`perceive` 佔掉大半就在 `config/local.yaml` 加 `vision: { mob_search_box: [700, 400] }` 只搜角色周圍（2554x1430 實測 135ms 降到 12ms），或把 `vision.mob_interval` 調成 0.3~0.5 秒才找一次怪（HP 和位置照樣每幀讀）。系統 CPU 已經 90% 以上就不是辨識參數的問題，把 `loop.fps` 調低比較實際——跑得穩比跑得快重要 |
| **按鍵沒反應（log 有顯示按鍵）** | 跑 `python tools/test_keys.py` 一次診斷完：它會檢查權限、前景視窗，並實際送鍵看有沒有被作業系統擋掉。最常見是遊戲用系統管理員執行而終端機沒有：Windows 的 UIPI 會**默默**丟掉一般權限行程送出的輸入，`SendInput` 回報成功、遊戲卻收不到，所以跑起來之後的 log 看起來一切正常。程式只在開跑那一刻檢查一次（遊戲提權了、bot 沒有，就印錯誤加警報），那行很快會被洗掉，往 log 開頭找。終端機也用「以系統管理員身分執行」開就好。順帶一提，提權後 PrintWindow 通常就拿得到畫面了，擷取不必退回 `screen`，遊戲被別的視窗蓋住也拍得對 |
| 忘了關 --dry-run | dry-run 會照常印出所有按鍵動作但**不會真的送出**。啟動時第一行有標示 |
| `找不到標題含「...」的視窗` | 錯誤訊息會**列出目前開著的視窗**，照抄一段填進 `window.title` 即可（預設 `新楓之谷：經典版`）。另外遊戲要用視窗模式 |
| 畫面像無限鏡像一直放大 | 擷取方式退回 `screen` 且偵錯視窗蓋住遊戲。用 `--snapshot` 就不會 |
| **每個 tick 都是 Wait、角色不動** | 不是當掉，是某條規則擋著。dry-run 的 tick 行括號裡就是原因；正式跑則會在閒置 20 秒後警告。最常見是小地圖紅點誤判成「有其他玩家」 |
| 誤判有其他玩家 | 用 `--snapshot` 看紅圈畫在哪。縮小 minimap region（別框到紅色 UI）、調低 `vision.color_tolerance`，或先設 `safety.pause_when_players: false` |
| 角色綠圈不見/亂跳 | 小地圖框太大含到雜物 → 重框；或調 `vision.color_tolerance` |
| **被撞到就說 HP 不夠停機** | 已修正：被打時血條會閃、那一幀讀成 0%，現在暴跌要下一幀再確認才算數。還會發生的話把 `vision.bar_confirm_frames` 調成 3 |
| HP/MP % 不對、**莫名說 HP 不夠就停機** | 血條 region 有問題。跑 `python tools/debug_view.py --track` 正常玩幾分鐘，看「突降」次數——大於 0 就是誤讀。重跑 `calibrate.py --write`，看它自動找到的 HP 讀數跟遊戲對不對得上；對不上就加 `--no-auto` 自己框，只框紅色條本體（不含數字、外框、旁邊 UI）。撐著先用的話把 `safety.critical_hp_frames` 調大 |
| `waypoints: auto` 一開場就停機，說量到的可走範圍太小（探邊失敗） | 會自動重試 2 次才放棄，所以多半是角色根本沒動：方向鍵沒送進遊戲（跑 `tools/test_keys.py`），或小地圖 region 框到了地圖畫布以外。`--dry-run` 本來就不會按鍵，預演時探邊一定量不到東西，那是正常的。怪太多一直被打斷的話，可改用手動 `waypoints: [左x, 右x]` |
| **一直不上樓**／log 都是「垂直移動連續失敗」 | 巡邏點裡繩子的 `x` 抄錯了：用 `python tools/debug_view.py --track` 站到繩子前重抄。x 沒錯的話，可能是角色移速快、`patrol.tolerance` 又大，停下來的位置離繩子太遠——有些繩的抓取窗口只有小地圖上 1~2px 寬，可以只對那個點收緊（`{x: 68, y: 20, tolerance: 1}`）；窄到站定跳也抓不到的繩改 `grab: run` 助跑跳。實例見 `config/profiles/弓箭手訓練場一-1366x768.yaml` |
| 突然停了，log 說「遊戲行程不見了」 | 遊戲當掉、被關掉或被踢下線。這是刻意的：再跑下去只會把技能鍵和方向鍵送進桌面或別的程式。不想要就設 `monitor.stop_when_game_exits: false` |
| 一直說沒賺到經驗 | 技能鍵對嗎？怪打得到嗎？先用 `--dry-run` 看決策是不是一直 `Move` |
| 走路一頓一頓的 | 已修正為持續按住方向鍵。還是頓的話多半是 `loop.fps` 太低（預設 8），或大視窗導致辨識太慢——見上面「反應變鈍」 |
| 走過頭來回震盪 | `patrol.tolerance` 調大（預設 4），或 `step_seconds_per_px` 調小 |
| 座標整組偏移 | Windows 顯示縮放改過 → 重跑第 2 步校正（程式已宣告 DPI aware，縮放不是 100% 也沒關係，校正一次就對得上） |

## 附錄：它怎麼決定下一步

每個 tick，`maplebot/brain/fsm.py` 的 `decide()` 由上往下看，第一條成立的就是這個
tick 的動作。大順序是**保命 > 補給 > 讓過其他玩家 > buff > 打怪 > 巡邏**：

1. 讀不到 HP 條或小地圖上的角色點 → 讓過（Wait）。小地圖角色點連續 `safety.lost_player_timeout`（預設 5 秒）找不到，看門狗會暫停並截圖
2. 整條狀態列不在畫面上（斷線、讀圖、換頻道）→ 讓過。這不是低血，灌藥或停機都是錯的反應
3. HP 低於 `safety.critical_hp_ratio` → 只開始計時、**不中斷**，下面的喝藥照常。連續 `critical_hp_frames` 幀、而且撐了 `critical_hp_seconds` 秒還拉不回來，才停機（設了 `panic_return_key` 先回城）
4. HP 低於 `potions.hp_emergency` 的門檻 → 按緊急藥（大瓶／全補，選配）
5. HP 低於 `potions.hp` 的門檻 → 喝藥。判定藥水用完時，設了回城卷就趁血還沒見底回城停機；沒設就改成每 20 秒試一瓶
6. MP 低於門檻 → 喝藥
7. 小地圖有其他玩家（`safety.pause_when_players`）→ 讓過，人走了自動繼續
8. buff 到期、MP 也夠 → 補 buff
9. 督導點名正在打的是掉落物 → 先撿起來，不然下一圈又會把它當成怪打
10. 攻擊範圍內有怪 → 照 profile 的順序，挑第一個冷卻好了、MP 夠、範圍內怪數達到 `min_mobs` 的技能施放：`directional` 先轉向最近的怪，`aoe` 原地放。兩個例外：
    - 原地連續打了 `safety.attack_stall_seconds` 秒位置都沒變（空揮）→ 讓路給巡邏 `attack_break_seconds` 秒
    - 遠程職業被貼臉（比 `keep_away_px` 近）→ 先退一步，下個 tick 再打
11. 範圍內沒怪了、剛打完怪（`loot.after_combat` 秒內，0 = 不限）→ 撿東西。清完場才撿，撿東西時被圍毆不划算
12. 看得到同一層的怪但構不到 → 追過去（`chase_px`），不越出巡邏路線的 x 範圍
13. `waypoints: auto` 還沒探邊完 → 往左右探邊。量到的範圍小於 `probe_min_span_px`，重試 `probe_retries` 次還是一樣就停機（不回城：那是設定或按鍵問題，不是危險）
14. 目前要去的巡邏點是 `descend: jump`、角色卻站得比那一層高 → 先跳下來，不等 x 對準（脫困跳躍常把角色送上路邊的小平台）
15. x 還沒對到巡邏點 → 走過去（走一步、重新讀一次小地圖）；途中位置 `stuck_seconds` 秒都沒變（卡住）就跳一下脫困，每次換一邊跳
16. x 到位但樓層不對 → 垂直移動（抓繩上下，或從平台往下跳）。每一步都確認小地圖 y 真的變了，失敗超過 `climb_retries` 次就放棄這個點；往上爬失敗時，同一層後面的點也一起跳過
17. 抵達 → 換下一個巡邏點；這個點掛了按鍵（`keys`，錄製時站定按的鍵就掛在這裡）就依序按一次

第 8～12 項在垂直移動途中整段跳過：掛在繩子上按方向鍵或技能鍵會掉下來。
