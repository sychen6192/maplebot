# 像素門檻一律以 790px 的 playfield 寬度為基準

所有用像素表達的設定——攻擊距離 `range_px`、描邊面積 `outline_min_area`、
名牌偏移 `nametag_offset`、追擊距離 `chase_px`——寫的都不是實際像素，而是
「playfield 寬 790px 時的像素」。執行時再按實際寬度等比例換算
（`REFERENCE_WIDTH`，可用 `attack_auto_scale` / `outline_auto_scale` 關掉）。

同一個世界距離在不同視窗大小下佔的像素完全不同：1920 視窗的 320px 只等於
790 視窗的 133px。不定基準的話，同一份 profile 換個視窗大小，攻擊範圍與怪物
面積門檻會整組跑掉，而且症狀是「怪就在旁邊卻不打」這種很難聯想到視窗大小的
表現。描邊面積門檻踩過一次這個坑：只把搜尋框餵給偵測器時，門檻按框寬縮放
會讓 `min_area` 從 3150 掉到 480，雜訊全變成怪。

## Consequences

看到 `range_px: 320` 在 2560 寬的視窗上跑，那不是 bug。要調這類數值時是調
790 基準下的值，不是調你螢幕上量到的像素。新增任何像素門檻都要一起決定它
是否需要縮放，並在註解裡寫明基準。
