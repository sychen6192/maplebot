# 只用畫面與模擬按鍵，不讀記憶體也不碰封包

這個 bot 的唯一輸入是螢幕擷取，唯一輸出是模擬按鍵。不讀寫遊戲記憶體、不攔截
封包，也不做任何反偵測。

讀記憶體其實更簡單也更準：角色座標、怪物清單、HP 都能直接拿到精確值，不用
處理描邊斷裂、血條被特效蓋住、JPEG 壓掉純黑像素這些問題。會繞這麼一大圈做
CV，是因為這個專案的題目**就是**即時電腦視覺與自動化控制，不是「用最省力的
方式打怪」。

換來的好處是整條 pipeline 可以完全離線開發與測試——一張靜態截圖就能重現
感知層的任何行為，不需要遊戲在跑。代價是所有辨識都是機率性的，因此才需要
`vision_ok`、血條去雜訊、連續幀確認這些防誤判的機制。

## Consequences

看到辨識不穩的地方，正確的處理是調門檻或補一層確認，不是「乾脆去讀記憶體」。
那會讓這個專案失去它存在的理由，也會讓離線測試整個失效。
